# Mosaici sui muri di Ravenna: una mappatura digitale

## Domanda provvisoria
Questo progetto esplora la presenza dei mosaici nello spazio urbano di Ravenna attraverso la fotografia, la documentazione e la mappatura digitale.

## Obiettivo
L'obiettivo è verificare e integrare la documentazione esistente sui mosaici urbani di Ravenna attraverso una nuova mappatura digitale.

*Il progetto è in fase iniziale. La domanda di ricerca e i criteri di selezione potranno essere rivisti durante la raccolta dei dati.*
